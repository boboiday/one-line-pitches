Entry for the make.fun bounty **A Day of One-Line Pitches** (`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`): one sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> Give your app idea one afternoon on make.fun: describe it in plain words, an agent builds a working first version for free, and if you hate it, you've lost nothing but an afternoon.

## How it works

`main.ts` (Node 22, stdlib only) writes the sentence to `/output/entry.txt`, exactly as the program/v1 harness requires. No network, no dependencies, deterministic — the same bytes on every run.

## Why this sentence

- **Concrete, not a slogan:** it names the deal in plain terms — one afternoon, plain words, a working first version, free.
- **Low risk, said out loud:** the friend's worst case is spelled out ("if you hate it…"), which is what makes handing the idea over feel easy.
- **True:** entering is free, and the agent builds a first working version from the friend's own description.
- **Warm:** it talks to one person about their idea, not to a market.
